adjustable muon detector

Particle detection // High-voltage electronics // Embedded systems

overview

An experimental cosmic-ray muon detector designed to detect high-energy particles passing through the detector using two Geiger–Müller tubes.

The project combines high-voltage power electronics, pulse conditioning, digital logic, mechanical adjustment, and embedded data acquisition into a single system.

objective

The goal of the project is to investigate the detection of cosmic-ray muons using Geiger–Müller tubes and to build the supporting electronics required to reliably identify particle events.

Using two detectors allows events occurring in both tubes to be compared, helping distinguish potential particle events from individual detector noise or background events.

detector system

The detector uses two SBM-20 Geiger–Müller tubes positioned with an adjustable separation. The mechanical arrangement allows the distance between the tubes to be changed for experimental measurements.

The detector electronics must provide a sufficiently high voltage for the Geiger–Müller tubes while also converting the resulting detector pulses into clean digital signals.

high-voltage supply

The Geiger–Müller tubes require a high operating voltage. A dedicated high-voltage supply was therefore designed as part of the project.

The supply uses a switching stage followed by a Cockcroft–Walton voltage multiplier to generate the high voltage required by the detector tubes.

Designing this section involved investigating switching frequency, duty cycle, transformer behaviour, diode selection, voltage multiplication, loading, and insulation.

signal processing

The pulses produced by the Geiger–Müller tubes are relatively short and require conditioning before they can be processed reliably by a microcontroller.

The planned signal-processing chain consists of several digital logic stages:

  • 74HCT14 Schmitt-trigger inverter
  • 74HC123 monostable multivibrator
  • 74HC08 AND logic
  • Arduino Nano for counting and data processing

coincidence detection

A key part of the detector is identifying events that are registered by both Geiger–Müller tubes within a defined time window.

The conditioned detector pulses can therefore be combined using digital logic to create a coincidence signal. This signal can then be measured by the Arduino.

The coincidence approach provides a way of reducing the influence of single-tube background events and makes the system more suitable for investigating cosmic-ray events.

adjustable geometry

The distance between the two detector tubes is mechanically adjustable. A servo-based mechanism is being developed to control the detector separation.

Buttons allow the user to change the detector position, making it possible to investigate how the measured event rate changes with detector geometry.

embedded system

An Arduino Nano is used as the control and measurement system. It processes the detector signals and provides the user with a simple interface for observing measurements.

The system is intended to display detector counts and coincidence events on an LCD while also controlling the adjustable detector mechanism.

engineering challenges

  • Generating and regulating the high voltage required by the Geiger–Müller tubes.
  • Producing reliable detector pulses from the tube output.
  • Designing digital logic capable of detecting coincidence events.
  • Preventing unwanted noise and false detections.
  • Integrating high-voltage electronics with low-voltage digital electronics.
  • Designing a mechanically adjustable detector assembly.

results

The project is being developed as an experimental particle detector, with the electronics and detector geometry being tested individually before integration into the complete system.

The final system will be evaluated by measuring detector counts and coincidence events and comparing the results under different detector configurations.
