4-bit von Neumann style CPU

Digital logic // Computer architecture

overview

A 4-bit von Neumann style CPU built using CMOS logic ICs on breadboards. The project explores the fundamental principles of computer architecture, digital logic, memory, instruction execution, and control logic.

architecture

The CPU is divided into several functional blocks:

  • Arithmetic Logic Unit
  • Registers
  • Control unit
  • Program counter
  • Memory
  • Instruction register
  • Input / output

implementation

The CPU is constructed from discrete CMOS logic ICs connected using breadboards. Each functional block was designed and tested individually before being integrated into the complete processor.

what can it do?

The processor can execute a small instruction set and perform operations on 4-bit values.

  • Load and store data
  • Perform arithmetic operations
  • Perform logical operations
  • Move data between registers
  • Execute conditional operations
  • Run programs stored in memory

results

The completed processor demonstrates how a programmable computer can be constructed from basic digital logic components rather than using a commercial CPU or microcontroller.
